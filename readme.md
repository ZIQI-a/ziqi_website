# Ziqi Archive 项目功能介绍

## 1. 项目定位

`Ziqi Archive` 是一个前后端分离的个人网站项目，主要用来作为互联网上个人存在的证明，集中承载个人介绍、博客笔记、项目作品、生活动态和公开联系平台；

总之项目本身没有什么新意的技术，就是玩，这个网站很早就想做了，现在终于是做了一个还算像样的了。

项目整体分为两部分：

- `ziqiHome_front`：前端工程，负责公开站点展示和后台管理端交互。
- `ziqihome_backend`：后端工程，负责公开内容接口、后台管理接口、登录会话、用户管理和数据持久化。

## 3. 公开站点功能

### 3.1 主页

主页是个人网站的首屏入口，主要用于展示个人基础信息、个人介绍、生活记录和近期动态。
![alt text](asset/image.png)
当前主页包含：

- 首屏个人介绍区
- 关于我 / 个人信息卡片
- 生活图文记录
- 文字类瞬间动态
- 侧边分区导航
- Moments 分类筛选
- 加载中、空状态、错误状态提示

### 3.2 最新动态

最新动态页以 `moments` 内容为核心，适合展示生活记录、随笔、图文动态等短内容。

页面能力包括：

- 展示带图 moments，形成生活切片区域
- 展示纯文字 moments，形成随笔区域
- 支持按 moments 分类筛选
- 图文内容和文字内容分区展示
- 分类切换时使用前端缓存，减少重复请求
- 支持加载、空状态和错误状态

### 3.3 博客笔记

博客页用于展示已发布的博客文章摘要。

当前支持：

- 博客列表展示
- 标题、发布时间、分类、摘要、标签、封面展示
- 后台维护 Markdown 正文、原文来源，以及站内详情/外链分发模式
- 后台将“标题 + Markdown 正文”独立为单独编辑页，并支持 Markdown 实时预览
- 后台支持通过语雀 Token 和知识库 namespace 手动预览并同步文章
- 只展示后台标记为 `published = true` 的博客
- 支持通过后端按关键词、分类和多标签交集筛选文章
- 支持加载、空状态和错误状态

当前阶段已支持博客详情页，并允许把部分文章配置为外链跳转。

### 3.4 项目工坊

项目页用于展示个人开发项目或作品集。

当前支持：

- 项目列表展示
- 项目名称、描述、技术栈、封面、访问链接展示
- 支持按项目阶段筛选，筛选项由后端根据已发布项目生成
- 项目阶段由后端枚举统一维护
- 只展示后台标记为 `published = true` 的项目

项目状态包括：

- 构思中
- 开发中
- 已完成

项目阶段只描述建设进度，是否展示到公开站由独立的 `published` 字段控制。

该模块适合记录从想法阶段到上线阶段的完整项目过程。

### 3.5 联系平台

联系页用于展示公开平台入口，例如个人主页、社交平台、代码平台或其他对外链接。

当前支持：

- 平台名称展示
- 平台图标展示
- 平台说明展示
- 桌面三列紧凑总览，移动端单列横向展示
- 整张平台卡片支持外链跳转和键盘访问
- 图标加载失败时使用平台首字母回退
- 只展示后台标记为 `published = true` 的联系平台

## 4. 后台管理端功能

后台管理端挂载在 `/admin` 下，需要登录后访问。前端通过路由守卫保护后台页面，后端通过 Session 拦截器保护 `/api/admin/**` 接口。

### 4.1 登录与会话

后台认证能力包括：

- `/admin/login` 登录页
- 登录成功后保存服务端 Session
- 进入后台路由时恢复当前会话
- 未登录访问后台时重定向到登录页
- 支持退出登录
- 用户被禁用或删除后，旧会话会失效

前端不自行保存 token，登录态以服务端 Session 为准。

### 4.2 管理首页

管理首页作为后台入口，用于承载后台导航和管理模块入口。

当前后台模块包括：

- 博客管理
- 项目管理
- Moments 管理
- 联系平台管理
- 用户管理

后台页面采用懒加载，避免管理端依赖影响公开站点首屏加载。

### 4.3 博客管理

博客管理用于维护公开博客列表内容。

支持字段包括：

- slug
- 标题
- 发布日期
- 分类
- 摘要
- 封面
- 标签
- 是否发布
- 排序值

支持操作：

- 查看博客列表
- 新增博客
- 编辑博客
- 删除博客
- 语雀文章预览同步

公开站点只读取已发布博客，并按排序值、发布日期和 ID 进行排序。

### 4.4 项目管理

项目管理用于维护个人项目内容。

支持字段包括：

- slug
- 项目名称
- 项目描述
- 项目状态
- 封面
- 项目链接
- 技术栈
- 项目亮点
- 是否发布
- 排序值

支持操作：

- 查看项目列表
- 新增项目
- 编辑项目
- 删除项目
- 获取项目表单选项

项目状态由后端枚举统一输出，技术栈候选项可从已有项目数据中汇总，方便后台表单复用。

### 4.5 Moments 动态管理

Moments 用于统一承载纯文字动态和带图动态。

支持字段包括：

- 动态内容
- 图片地址
- 图片描述
- 分类
- 是否发布
- 是否展示到首页
- 是否置顶
- 创建时间
- 更新时间

支持操作：

- 查看 moments 列表
- 按分类筛选
- 按发布状态筛选
- 新增 moment
- 编辑 moment
- 删除 moment

公开站点永远只消费已发布 moments。首页只请求一次 `showOnHome=true` 的后台精选结果，并按后端顺序展示最多三条图文和两条文字；瞬间页通过 `categoryId` 完成分类浏览。`hasImage` 参数继续作为接口能力保留，不参与当前首页的数据拆分。

### 4.6 Moments 分类管理

Moments 分类用于给动态内容提供稳定归属。

支持操作：

- 查看分类列表
- 新增分类
- 编辑分类
- 删除分类

业务规则：

- 分类名称不能重复。
- 已被 moments 使用的分类不允许删除，避免历史内容失去归属。

### 4.7 联系平台管理

联系平台管理用于维护联系页展示的公开平台入口。

支持字段包括：

- 平台名称
- 平台主页地址
- 图标地址
- 描述
- 是否发布
- 排序值

支持操作：

- 查看联系平台列表
- 新增联系平台
- 编辑联系平台
- 删除联系平台

公开联系页只展示已发布平台，并根据排序值控制展示顺序。

### 4.8 用户管理

用户管理用于维护后台账号。

支持字段包括：

- 用户名
- 昵称
- 角色
- 是否启用
- 最近登录时间
- 创建时间
- 更新时间

支持操作：

- 查看用户列表
- 新增用户
- 编辑用户资料
- 单独修改用户密码
- 删除用户
- 启用或停用用户

密码不会明文保存，后端使用 BCrypt 存储密码哈希。密码更新被设计成独立接口，避免普通资料编辑时误覆盖敏感字段。

## 6. 技术栈

### 6.1 前端技术栈

- Vite
- React
- TypeScript
- react-router-dom
- CSS Modules
- Ant Design
- ESLint

前端公开站点主要使用 CSS Modules 和主题变量维护样式，后台管理端局部使用 Ant Design 组件。

### 6.2 后端技术栈

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Validation
- Spring Security Crypto
- Flyway
- MySQL
- H2 测试数据库
- JUnit / MockMvc
