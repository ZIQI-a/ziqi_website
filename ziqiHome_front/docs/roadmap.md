## 公开站点六阶段优化路线

1. **公共移动端导航**：将小屏 Header 收敛为单行顶栏与下拉菜单。（已完成）
2. **Latest 帖子流**：统一图文和纯文字 Moment，使用紧凑双列瀑布流。（已完成）
3. **首页内容收敛**：减少 Moments 重复展示，补充完整内容入口和共享错误状态。（已完成）
4. **Contact 紧凑化**：统一标题体系，优化三列平台卡片和移动端列表。（已完成）
5. **Projects 业务闭环**：规范项目阶段、公开状态、校验、排序及公开接口。
6. **Blog 内容质量**：优化重点卡片留白、摘要质量与默认封面辨识度。

每阶段按功能模块独立验证并创建中文本地 Git 提交；测试与工程治理作为六阶段后的持续任务。
